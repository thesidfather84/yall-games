# Y’all Games studio website

Static production source for https://www.yallgames.com, Vercel project yall-games. Serve public/; deployment configuration is in vercel.json.

Website-only branch codex/website-two-games. No game worktree is included or changed. Two separate products: Endless Bay (Android, Coming soon/closed testing being prepared), Save the Shell (Windows/Steam, Coming soon, planned 100-level campaign). XERETHA remains a separate future project. No store URLs are invented.

Existing Louisiana bayou identity, studio imagery, logo, tagline, contacts and privacy policy retained. save-the-shell-flyer-v1.png is the owner-approved original promotional flyer generated using only Y'all Games' original turtle and reef references. Generation prompt and approval are retained under artwork-provenance/. It is not presented as a gameplay screenshot. Existing Endless Bay and studio artwork are unchanged. No project prices or invented store URLs appear on the website. No Android build or Steam files were modified.
